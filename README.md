**A season that never ends.**

ZEROBASEONE × ZEROSE 的粉絲互動宇宙。第一版使用 HTML、CSS、JavaScript、JSON 與 LocalStorage，無需登入或後端。

## 已實作
- 夏日主視覺、響應式導覽與三世界入口
- 可點擊宇宙地圖、三世界解說
- 九位成員與專屬星球彈窗
- 時間軸、明確標示虛構的 FOREVER NINE 故事
- 每日星光領取、任務清單與星星累積
- 個人日記、漂流瓶、社群貼文及按讚
- 個人收藏儀表板，資料儲存在瀏覽器 LocalStorage
