# OUR SEASON ✦
**A season that never ends.**

ZEROBASEONE × ZEROSE 的粉絲互動宇宙。第一版使用 HTML、CSS、JavaScript、JSON 與 LocalStorage，無需登入或後端。

## 本機啟動
因為資料以 `fetch()` 載入 JSON，請使用 HTTP server：
```bash
python -m http.server 8000
```
開啟 http://localhost:8000

## 已實作
- 夏日主視覺、響應式導覽與三世界入口
- 可點擊宇宙地圖、三世界解說
- 九位成員與專屬星球彈窗
- 時間軸、明確標示虛構的 FOREVER NINE 故事
- 每日星光領取、任務清單與星星累積
- 個人日記、漂流瓶、社群貼文及按讚
- 個人收藏儀表板，資料儲存在瀏覽器 LocalStorage
- V2：成員星球探索獎勵每位成員限領一次
- V2：每日任務由探索世界、閱讀故事、查看星球及保存日記等行動觸發，完成後不能重複領取
- V2：平行日常卡片可點擊／鍵盤開啟故事閱讀視窗
